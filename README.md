## 📖 Overview

SmartCampus is a comprehensive Campus Management System built using **Spring Boot**, **MySQL**, and **Thymeleaf**. The platform centralizes academic and administrative operations, enabling efficient management of students, faculty, attendance, grades, and campus resources.

---

## ✨ Key Features

### 👨‍🎓 Student Portal
- Student Registration
- Attendance Tracking
- View Grades & Results
- Academic Information Access

### 👨‍🏫 Faculty Portal

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/BhagyasreeJena/SmartCampus.git
```

### Navigate to Project

```bash
cd SmartCampus
```

### Configure Database

Update MySQL credentials in:

```properties
application.properties
```

### Run Application

```bash
mvn spring-boot:run
```

### Open Browser

```text
http://localhost:8080
```
